# Finova AI Expense Intelligence Suite

An industry-style personal finance and expense tracker built for final year project submission using React, Tailwind CSS, GSAP, Recharts, and local persistence.

## Core Features

- Smart expense categorization based on transaction descriptions
- Monthly reporting with trend and category charts
- Budget alert engine with editable monthly caps
- AI-style savings suggestions generated from spending behavior
- Recent activity tracking and transaction entry workflow
- Bank API integration section for optional backend expansion

## Tech Stack

- React 19 + Vite
- Tailwind CSS
- GSAP
- Recharts
- date-fns
- lucide-react
- LocalStorage for demo persistence

## How to Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
